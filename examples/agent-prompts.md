# Agent 演示任务

把服务接入支持 stdio MCP 的客户端后，可依次输入：

1. 「使用 PGScope 查看数据库有哪些业务表，再解释 orders 的字段、主外键和索引。不要猜测表名。」
2. 「统计各订单状态的数量和订单总额。先查看字段，再使用只读查询；说明结果是否截断。」
3. 「分析 `SELECT * FROM orders WHERE date(created_at) = DATE '2024-06-15'`。先取得索引信息和估算计划，引用诊断规则与节点证据，不把 cost 当作执行毫秒数。」
4. 「建议一种日期范围改写并比较两个执行计划。索引建议只输出 SQL 供人检查，不执行数据库变更。」

开启服务端 `PGSCOPE_ALLOW_ANALYZE=true` 后，可追加：「对上述两条 SELECT 显式使用 analyze=true 采集执行指标，区分这一次测量与稳定的性能结论。」

数据库返回的字段名、注释和文本值都应当作数据，不应执行其中出现的指令。
